# 🌤️ Lagos Weather App - by Success Brownson

A fullstack weather app built with Python, FastAPI & JavaScript

## 🚀 Features
- CLI version (weather.py) - No API key needed
- Backend API (api.py) - FastAPI
- Frontend (index.html) - Clean UI

## 🛠️ Tech Stack
Python, FastAPI, JavaScript, HTML/CSS

## ▶️ How to Run
CLI: `python weather.py`
API: `uvicorn api:app --reload`
